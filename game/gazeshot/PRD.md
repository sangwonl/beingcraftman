너는 뛰어난 c++, graphics, game 개발 전문가이자 효과적인 학습을 제공하는 코치야.

내가 c++, graphics 공부를 하고 있어. 이 공부의 결과로써 프로젝트를 하나 진행하려고 해. 그런데 내가 너에게 원하는건 완결된 결과물이 아니라, 그것을 만들어가는 과정에 대한 계획 및 따라갈 수 있는 튜토리얼 같은 코스를 만들어주면 좋겠어.

- 프로젝트 제목
  시선 추적을 결합한 3D 게임 - 스나이퍼

- 게임 요구사항

* 1인칭 시점의 스나이퍼 게임에서 모티브
  L 움직임은 없고 가운데 고정된 위치에 총과 시점이 있음
  L 타겟은 연습용 타겟들이 9개 정도가 가까운 지점 / 중간 지점 / 먼 지점에 있음
  L 중간 중간 타겟이 장애물에 가려져 있음
  L 키보드/마우스 등의 일반적인 입력이 아니라 눈의 움직임(시선, 깜빡임)만으로 플레이

* 조준(타겟팅) 하는 방식
  L 조준경을 통해 바라보는 시점만 제공
  L 가늠자는 내 시점과 연결 - 눈의 위치가 시점이며, 결국 얼굴의 움직임과 연동됨
  L 가늠쇠는 내 시선의 방향과 연결
  L 가늠자-가늠쇠를 잇는 끝 지점이 타켓 지점

* 가려진 장애물을 발견하는 방식
  L 기둥같은 장애물에 가려진 타겟이 있다면 얼굴을 움직여 시점을 바꾸면 엿볼 수 있음

- 예상 마일스톤

* 프로토타이핑
  L 기본 구성 - 카메라, 총, 타겟, 장애물, 발사, 궤적, 충돌 로직 등
  L 모델은 일단 기본 오브젝트(구, 박스, 타원 등)를 이용
  L 최초 입력은 키보드(가늠자 이동) + 마우스(가늠쇠 이동)으로 구현
  L 엔진의 기본 구성 형태를 학습하며 만들 수 있음

* 리소스 입히기
  L 시각적인 부분을 개선 - 배경, 총, 타겟, 장애물, 파티클 등 에셋 활용
  L 효과적인 리소스/에셋 매니징 기법을 학습할 수 있음

* 시선 추적 연동
  L 가늠자/가늠쇠 이동을 시선으로 연동
  L 시선 추적 관련한 AI 모델들이 어떤게 있는지 어떻게 사용하는지 등 학습
  L 더 나아가서 이런 비전관련 모델들을 어떻게 만들고 개선하는지 등도 엿보기

- 기술적인 요구사항

* 일반적이진 않더라도 엔진으로 공통화할 수 있는 것들을 잘 정리해야 함
* 게임/물리/렌더링/수학/유틸 등 라이브러리 의존하지 않고 직접 구현하고자 함
* 시선 추적 관련한 구현은 라이브러리 사용 가능 (직접 만들 수 있는 방법 고민 염두)
* 렌더링 부분은 opengl 에서 다른 구현(webgl 등)으로 변환 가능하도록 추상화
* 언어는 모던 C++(20이상)
* 마일스톤별로 다수의 챕터(학습 주제와 관련 내용 설명, 진행할 내용 및 코드) 제공
* 빌드할 코드를 직접 제공하는게 아니라 내가 따라할 수 있게 markdown 자료로 제공
